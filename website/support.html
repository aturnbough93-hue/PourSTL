Questions and support

Updated November 6, 2026. Pour is in development. This website does not offer a support inbox, chat, or account help desk.

How to ask

For general questions, open a GitHub issue. Do not include personal information, credentials, or vulnerability details in a public issue. Use the repository's private vulnerability reporting option when it is available.

The privacy page describes how the current app, this website, and the browser demo handle data.
