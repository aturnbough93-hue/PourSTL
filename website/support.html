Questions and support

Updated November 12, 2026. Pour is in development for iPhone with iOS 17 or later. You can try the browser demo now. A public App Store or TestFlight download is not available yet.

A quick test to try

  1. In the browser demo, open “Show ingredients” on smaller screens. Remove Campari from My Bar and watch the Negroni show a missing ingredient.
  2. Select Daiquiri, increase servings, and switch between oz and ml. Check that the measures change together.
  3. Choose “Add missing to list” to build a shopping list. Mark an item purchased to restock it, then use “Copy recipe” to share the spec.

Browser demo help

Your bar did not save? The demo saves in this browser on this device. Private browsing or blocked site storage may prevent it from surviving a closed tab. The storage note tells you when changes will last only for the tab session.

Copy is blocked? The demo offers a text box so you can select and copy the recipe yourself.

Want to start over? Choose “Reset demo” and confirm. This restores the starter bar and clears the demo’s saved shopping list. It does not change the iPhone app.

Report a problem or suggest an improvement

Open a GitHub issue and include:

  • Whether you were using the website, browser demo, or an iPhone test build.
  • Your browser and operating system, or your iPhone model, iOS version, and app build.
  • The steps you took, what you expected, and what happened instead. A screenshot can help.

GitHub issues are public. Remove personal information from screenshots and never include passwords, payment details, or credentials. For a security concern, use the repository’s private vulnerability reporting option when it is available instead of posting vulnerability details publicly.

Testing the iPhone app

If you are building Pour in Xcode, follow the project setup instructions. Barcode scanning needs an iPhone camera, with manual entry available in the simulator or when permission is denied. Pro purchase and restore checks currently use a local StoreKit test configuration, not a public subscription.

The offline Bar Assistant can answer supported recipe and inventory questions from this device. Try “What can I make?” or “Scale Negroni for 4.” It uses local rules, so ask a specific recipe question if it cannot understand a request.

The privacy page describes how the current app, this website, and the browser demo handle data.
