# Pour

**Pour** is a planned native iOS bartender's assistant — a fast, offline-first recipe, inventory, and service tool for working bartenders.

The intended scope is a dark-mode-first SwiftUI app with a copper-accented design system, a seeded library of classic cocktails, "what can I make" inventory matching, scaling/batch mode, a shopping list, timers, and custom recipes.

## Status

The initial SwiftUI implementation was reverted (see #1 / #3). There is currently no app source, Xcode project, or test target in this repository.
